# Symbols

Use the command `help symfont` for Alphabet chars and fonts. 

Tematic list of symbols from `jlabbrev` plugin to copy-paste and some other.

If `CHXTemplates` is installed, general templates have these symbols added.

> **Note**: Keywords with "*" are `CHXTemplates` only.
